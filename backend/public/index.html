🔧 TRIJAL ENTERPRISES API

Welcome to the TRIJAL ENTERPRISES backend API. This API powers the drilling services management system.

Available Endpoints

POST /api/contact

Submit a contact form inquiry

GET /api/projects

Get all projects

GET /api/projects/{id}

Get a specific project

POST /api/projects

Create a new project

PUT /api/projects/{id}

Update a project

DELETE /api/projects/{id}

Delete a project

POST /api/quotes

Create a quote request

GET /api/quotes/{id}

Get quote details

Note: All endpoints expect JSON data. Ensure proper CORS headers are set for cross-origin requests.
